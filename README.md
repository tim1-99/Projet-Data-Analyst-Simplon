# Projet Data Analyst Simplon

## Description

Ce projet consiste à analyser les ventes d'une PME à l'aide de SQL et Python.

## Technologies utilisées

- SQL (SQLite)
- Python
- Pandas
- Plotly

## Analyses réalisées

- Analyse des ventes par produit
- Calcul du chiffre d'affaires
- Création de graphiques interactifs

## Fichiers

- main.py
- ventes.csv
